# 当前底图风格

正式校园层已切换至 OSM 地理底图，最新范围、标注规则、配色及重建说明见 [GEO_BASEMAP.md](GEO_BASEMAP.md)。原始数据检查预览 `?basemap=osm` 保留。下文保留此前图纸坐标版本的设计记录。

已按项目所有者选择，采用以 2D 为主的校园景观总平面，替换早期三款试选配色。

- 普通建筑：暖白色、浅灰直线轮廓、轻微投影。
- 交互地点：浅黄、浅粉、浅紫、浅绿等柔和颜色的矩形，以轻微侧面呈现 2.5D。
- 背景：灰绿色草地、树冠、低对比道路、浅青色水体。
- 布局：按参考校园图的相对位置组织，不依赖经纬度、在线瓦片或地图服务。
- 命名：普通设施参考校园图；食堂与餐车以定位图文件名为准。

维护位置与来源见 [CAMPUS_PLAN.md](CAMPUS_PLAN.md)。完成建筑群建模后，沿用场所 ID 和锚点替换矩形。
