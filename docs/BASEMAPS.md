# 底图选择

**建议先选清新校园作为视觉方向，真实地理底图优先试 MapLibre + OpenFreeMap 的 Positron，再叠加自采校园道路与建筑。** 先验证仙林校区的数据完整度和校园网加载速度，再决定是否使用线上瓦片。地图 SDK 和底图数据源是两个不同选择。

## 已做好的三款视觉预览

右下角「底图风格」直接切换；三款都是相同示意几何的配色方案，不是三份真实地理数据。

| 方案               | 样子                                       | 适合                               |
| ------------------ | ------------------------------------------ | ---------------------------------- |
| A 清新校园（默认） | 雾绿地面、浅蓝水体、南大紫建筑、低饱和背景 | 日间探索，食堂突出、校园感明确     |
| B 暖纸手绘         | 奶油纸色、灰绿植被、陶土色食堂             | 温暖的校园生活指南，适合照片卡片   |
| C 紫夜漫游         | 深灰紫地面、冷色水体、淡紫食堂             | 夜间使用或活动专题，需保持文字对比 |

## 可接入的真实最外层底图

| 候选                                    | 优势                                              | 需处理                                                 |
| --------------------------------------- | ------------------------------------------------- | ------------------------------------------------------ |
| MapLibre + OpenFreeMap Positron         | 浅色简洁，业务建筑容易突出；开源渲染，可迁移      | 校园建筑细节与国内网络需实测，保留来源署名             |
| MapLibre + OpenFreeMap Liberty / Bright | 道路、地物更完整；可调整样式 JSON                 | 默认 POI 可能拥挤，需要隐藏无关标签                    |
| 高德 JS API 2.0 简洁底图                | 中文道路与周边生活信息，国内服务接入便利          | 注册 Key，按当时配额/授权；使用 GCJ-02；供应商绑定更强 |
| 自有校园矢量底图                        | 最容易与校园风格、2.5D 建筑统一；文件可随项目迁移 | 需要授权来源和真实配准；制作与更新工作更多             |

[OpenFreeMap 官方可交互样式对比](https://openfreemap.org/quick_start/) 提供 Positron、Bright、Liberty、Dark 等预览，可以直接查看风格。不要把这个提供方的示例地图当作本项目已经接入的校园地图。

[MapLibre 建筑拉伸示例](https://maplibre.org/maplibre-gl-js/docs/examples/display-buildings-in-3d/) 适合校园 2.5D 建筑；独立室内场景继续用 Three.js，不必引入 Cesium。

高德的坐标使用规则见 [官方坐标转换说明](https://developer.amap.com/api/javascript-api-v2/guide/transform/convertfrom)。OSM 数据与瓦片服务不是一回事：使用 OSM 数据保留署名，不能将社区标准瓦片当作无限量免费 CDN 或批量离线下载服务，见 [瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)。

## 选型后的下一步

选风格后，仅采集一栋食堂进行完整流程试点：校园定位、入口锚点、楼层原点和朝向、6–10 个真实窗口。校准通过后再扩展全部场所。用户提供的校园图用于当前布局参考，公开使用原图前需确认来源与许可。

以上服务文档于 2026-10-21 核实；价格、配额和接入细节以实际申请时的官方条款为准。
