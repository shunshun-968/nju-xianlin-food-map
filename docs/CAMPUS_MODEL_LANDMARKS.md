# 校园总览中的真实餐饮外观

外层地图的六个已建模地点使用 Three.js 模型预渲染的透明图像：四五六食堂、民族八九食堂、第十／教工食堂、十一十二食堂、南门餐车和逸夫楼售卖点。食堂与餐车保留真实屋顶、玻璃、红砖、入口楼梯与棚顶；逸夫楼按用户要求使用白色有门的小屋示意标记。

## 显示与交互

- 校园底图仍为 SVG。普通建筑使用平面轮廓，地面阴影减弱；真实食堂模型放大 14%，增加柔和阴影、微高光与悬停抬升。OSM 显示矩形原本为真实包围矩形的 84%，该放大仍接近真实足迹。
- 复用原来的场所 ID、鼠标点击、键盘 Enter／空格、侧栏高亮以及拖动／缩放识别。没有在总览中运行额外 WebGL 场景。
- 南门餐车以已确认的售卖面朝南表现；按用户调整，宽高各缩为上一版的约 70.7%，面积减半（总览最小宽约 12.7 屏幕像素）。地面锚点和原点击范围保留，命中范围仍至少 24 屏幕像素。
- 五个真实模型不再常驻名称标记。电脑悬停或键盘聚焦时，名称气泡在建筑上方平滑浮现，移开后淡出；鼠标点击、Enter／空格仍直接进入。
- 手机或触摸输入先显示名称及“再点一次进入”，再次点同一建筑或名称气泡才进入。点另一地点只切换预览，点空白、拖动、双指缩放或复位会取消待确认状态；触摸自动聚焦不算首次确认。侧栏仍直接进入。
- 标签优先放在模型外侧，普通建筑和道路文字也避让模型。在极近缩放没有外侧放置空间时，保留名称的可访问性。总览中扩大的点击区如果重叠，按最近的实际建筑图形匹配，避免四五六被相邻小餐车的透明点击区遮住。
- 昼夜图片共用完全相同的投影边界和地面锚点；夜间保留外观窗口／入口灯光，与校园已有路灯叠合。减少动态效果偏好下不执行悬停过渡。
- 逸夫楼模型的宽高在每一级缩放均不超过南门餐车的 1.05 倍，位置仍使用原有室内点位。它不显示常驻、悬停或触摸文字标签；鼠标、键盘和触摸均直接进入第二层。侧栏及无障碍名称保留。
- 逸夫楼的小图显示完整白墙、平顶屋顶与清楚的南侧门，夜间保留少量暖色门光。它使用独立的 `src/models/exteriors/yifu-map-house.ts`，只作地图示意，不代表整栋邵逸夫楼的真实外轮廓。进入第二层后仍显示原有的详细室内模型。
- 美食小屋继续保留原标记。

## 坐标与资源

地理定位仅使用 `public/osm/campus-render.json`／运行时元数据的 `MapVenue.point`，不使用旧的 `src/data/campus.ts` 图纸坐标。图片按地面中心定位，不能将包含屋顶上移的图片中心作为地理锚点。

`src/assets/campus-models/manifest.json` 保存各图相对地面中心的 `offsetX/offsetY/width/height`（地图米）以及参考矩形尺寸。图像已经包含朝向和斜投影，SVG 中不再次旋转。由于最小包围矩形轴可能交换，四五六／第十减 90°、十一十二加 90°、民族八九使用原矩形角；模型自身已有的根旋转先保留。餐车直接使用已确认的南向。

以 `(x, z-y)` 投影表现高度，先按现有地图足迹统一缩放模型，纵向高度稍增至 1.2 倍。渲染排除独立预览的场地、树木、入口标记，以及十一十二的远处道路斜坡；保留近建筑入口。透明通道保存在 WebP 内，长边 1024 像素。

## 更新模型后重新导出

1. 从仓库根目录运行开发服务器，默认 `npm run dev -- --port 5173`。
2. 打开 `http://127.0.0.1:5173/nju-xianlin-food-map/scripts/render-campus-models.html`。
3. 页面可直接选择地点、昼夜主题并点击“渲染模型”，下载透明 WebP 和读取投影元数据；仍保留 `window.renderCampusSprite(id, night)` 接口。按六个 ID、昼夜两版顺序运行，避免多个渲染任务竞争同一 WebGL 上下文。
4. 可使用 Playwright CLI 打开该页面，再以 `run-code --filename scripts/export-campus-models.cjs` 批量保存到 `src/assets/campus-models/`；从仓库根目录执行，脚本采用相对输出路径。
5. 更新图片与 manifest 后运行 `npm test` 和 `npm run build`，检查各地点定位、昼夜切换及点击入口。

`scripts/render-campus-models.html` 仅为开发导出工具，不是网站入口；生产网站只加载当前主题的六张图片，不读取本机照片路径或远程图片。
