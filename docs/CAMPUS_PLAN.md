## 坐标与维护

`CAMPUS_PLAN_V2` 为 1280 × 1920 的相对图纸坐标，X 向右、Y 向下，不是经纬度或米。接口使用 `campusPosition: [x, y]`；数据库沿用 `campus_x/campus_z` 字段名称。窗口局部坐标独立，仍属于演示布局。

- `src/data/campus-layout.json` 保存初始提取结果，作为植被、运动场和源定位边界的底稿；不再用于显示建筑、道路或水体。
- `src/data/campus-drawing.json` 保存人工对照原图整理的建筑翼楼、院落、道路中心线、水体曲线及道路名锚点。
- `src/data/campus.ts` 保存交互点中心、朝向、尺寸、配色、源文件名及普通设施名称。
- `src/components/CampusMap.tsx` 实现拖动、滚轮/双指缩放、键盘操作、分级名称和点击入口。
- `scripts/trace-campus.py` 从规范化为 1280 × 1920 的 24 位 BMP 提取底图；仅使用 Python 标准库。
- `scripts/draw-campus.py` 保存人工描绘的几何源数据，运行 `python scripts/draw-campus.py` 可重新生成展示图层。M/S/N 分别对应原图放大至 2560 × 3840 后，起点为 (380, 980)、(500, 2110)、(960, 300) 的核对区域；P 为 1280 × 1920 整张图。脚本统一转换回 V2 图纸坐标。
- `src/lib/map-labels.ts` 在屏幕像素空间统一排版普通名称和场所标签，计算旋转后的边界并避让。

建筑采用人工整理的直线翼楼、真实院落及连廊示意，替代逐像素自动描边。毓秀院等建筑群按分开的翼楼表达；主要道路使用有宽度的中心线和二次贝塞尔曲线，水体单独绘制平滑岸线。这是参考图的简化转绘，不是实测建筑模型。树木和等高线状纹理为景观风格表达，不代表实测树位或高程。原始参考图不随前端发布。

食堂标签优先，普通建筑名称随放大逐级出现；拥挤时隐藏较低优先级名称，不重叠堆放。可通过左侧列表访问全部场所。右下角可隐藏名称。道路名称的位置直接从对应道路中心线求得，并沿该点的切线方向排布；避让时只能隐藏，不能移动到道路外。修改道路几何后应重新运行绘制脚本生成锚点。后续精细建筑群模型仍通过稳定场所 ID 绑定，无需重编窗口归属。

## 旧版本兼容

旧 `CAMPUS_SCHEMATIC_V1` 示例坐标不能直接套用新底图。新种子使用 V2，API 返回保存的坐标版本，前端拒绝混用。Pages 目录随代码自动更新。

若曾手动部署旧种子数据库，应先备份，再按稳定 ID 更新七个 venue 的名称、campus_x/campus_z、footprint 和 coordinate_system，不要清空真实业务数据库。当前尚未接入线上数据库。

按当前要求无需地图 Key、在线瓦片或地理配准。只有未来明确增加 GPS 导航时才另行设计地理坐标转换。

## OSM 比例尺校准（2026-10-21，本地界面修订）

比例尺按用户要求显示 `100 m`、`200 m` 等整洁刻度，不加“约”，随 SVG 缩放自动更新。它表达屏幕水平方向的直线距离，不表示步行路径长度。校园几何及业务坐标仍为 V2 相对图纸坐标。

数据读取自 [OpenStreetMap 官方地图 API](https://api.openstreetmap.org/api/0.6/map?bbox=118.95,32.11,118.97,32.13)。选取四五六食堂、民族食堂八九食堂、第十食堂、天文学院、左涤江天文台共五个建筑外接框中心作为对应点。源要素链接、WGS84 坐标、图纸位置及结果保存在 `src/data/map-calibration.json`，计算过程为 `scripts/calibrate-scale.py`，前端无需联网查询 OSM。

采用 WGS84 局部东西/南北米制坐标进行最小二乘仿射拟合，分别处理原图横纵比例：水平 1.515359 米/图纸单位，垂直 1.568751 米/图纸单位。五个控制点拟合残差 RMS 为 2.97 米，最大 4.81 米。**这些残差仅描述控制点拟合，不能视作整张示意图的精度保证**；手工转绘、OSM 建筑范围及参考图局部变形仍会产生误差。比例尺 tooltip 保留这一说明。

复算：下载上述 XML 后运行 `python scripts/calibrate-scale.py <path-to-osm.xml>`。`src/lib/map-scale.ts` 将水平米制单位转换成当前屏幕像素，并选用 1/2/5 系列刻度。“关于食光”中保留 [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) 来源链接；数据遵循 ODbL。
