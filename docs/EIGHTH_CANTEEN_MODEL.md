# 第八食堂窗口模型

依据用户手绘俯视图、工作区 `第八食堂内部/1.jpg` 至 `5.jpg`、`1-2转角.jpg` 及用户逐项复核建立。照片文件名中的数字是拍摄区段；照片里的紫色号牌才是真实窗口编号。

默认进入俯视揭顶模式，手动切换到 3D 后观察同一套窗口模型。建模沿用第五食堂的比例化柜台、玻璃、牌坊与厨房表现方式，并根据第八食堂照片使用黄色牌坊、白色瓷砖柜台和独立水饺冰柜。照片用于建模参考，不作为菜单图片或模型贴图公开。

当前暂挂在现有建筑的 `v-891-f2` 技术入口，直达参数为 `?floor=v-891-f2`。**这不是实测确认的建筑楼层；用户已说明外部建筑以后调整，本次优先完成室内。** 修改外部入口时应同步迁移引用，不从名称推断真实楼层。

## 真实窗口与售卖对应

共有 **14 个有真实号牌的售餐窗口、7 个牌坊面，以及 1 处独立水饺超市冰柜**。窗口选择数据共 15 条，冰柜没有编造窗口编号。

| 实际号牌   | 当前售卖                | 牌坊分区         | 经营关系                         |
| ---------- | ----------------------- | ---------------- | -------------------------------- |
| 1、2       | 减脂餐                  | 卤水             | 两窗同一档口                     |
| 3          | 未知，界面只称“3号窗口” | 特色             | 不推断售卖内容或与相邻窗口的关系 |
| 4、5、6、7 | 自选菜                  | 特色、味道、主食 | 四窗同一档口                     |
| 8          | 吊梨汤                  | 主食             | 独立售卖记录                     |
| 9          | 鸡排饭／牛排饭          | 铁板             | 同一窗口的两类售卖               |
| 10、11     | 面食                    | 铁板、面坊       | 两窗同一档口                     |
| 12         | 暂无售卖                | 面坊             | 保留真实窗口，不伪造餐品         |
| 13、14     | 椰子鸡                  | 美食             | 两窗同一档口                     |
| 无号牌     | 水饺超市                | 独立冰柜         | 与 L 形窗口分开定位              |

“卤水、特色、味道、主食、铁板、面坊、美食”是装饰牌坊名称，**不能据此推断窗口实际卖什么**。照片中六块长边牌坊和电子屏连续排列；数据按相邻两个窗口的牌坊分区管理，实际经营分组可以跨越牌坊。

牌坊和实际售卖分别保存在 `name` 与 `windowLabels`。`windowNumbers` 保存真实号牌，`shopIds` 保存用户确认的经营分组；同一档口的多个窗口仍各有固定位置和稳定 ID，不能合成一个没有实际位置的大窗口。模型中的单数 `shopId` 则仅供复用厨房结构，尤其转角的结构复用不表示面食与椰子鸡是同一经营档口。

菜单、价格、实拍详情和用户内容尚未采集，本次全部保持空数据；3 号窗口与 12 号窗口不能填入默认演示菜品。

## 朝向与位置

俯视图北向上：`+X` 为东（屏幕右），`−Z` 为北（屏幕上）。长排 1—12 号由西向东，向南（`+Z`）售餐；东端转角后的 13、14 号从南向北排列，向东（`+X`）售餐。没有绘出的桌椅、门、楼梯及其他区域留空，不推断完整房间轮廓。

窗口使用显式牌坊中心坐标、局部窗口偏移与旋转角建立映射。长边六个牌坊中心 X 为 `−12.75、−8.25、−3.75、0.75、5.25、9.75`，Z 均为 `3`，朝向为 `0`；东侧“美食”中心为 `(11, 1.75)`，朝向为 `π/2`。每个牌坊宽 `4.5`，每窗宽 `2.25`，厨房进深 `3.5`。**以上为浏览友好的示意比例，不是实测米制尺寸。**

转角厨房示意范围为 `X=7.5…12、Z=−0.5…4`，南、东两面开放。水饺超市单独定位于 `(9, 7.4)`，柜体尺寸 `3.4 × 1.5`、朝向 `π/2`，长边沿南北方向，垂直于窗口长排（按用户更正及 `2.jpg`）；它不属于 12 号窗口，也不与转角窗口合并。

调整列表顺序不会改变坐标。每个窗口 ID 由固定牌坊 ID 与局部 `-w1` / `-w2` 后缀组成；后缀仅是程序标识，显示时必须读取真实 `windowNumbers`，不能把局部后缀或数组索引显示成窗口号。

## 验证

数据、实际 Three.js 几何与射线测试覆盖真实编号、同档口关系、转角朝向、独立冰柜、空窗口及俯视／3D 切换。冰柜使用符合柜体的点击高度，避免其上方空白区域截获后方窗口的点击；普通窗口仍使用柜台底部至招牌顶部的完整点击范围。

浏览器验证包含桌面与手机端入口、详情内容、默认俯视，以及 3D 放大后关闭详情保持视角。动态效果暂停时，关闭详情前后的模型区域截图完全一致。
