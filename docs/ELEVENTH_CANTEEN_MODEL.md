# 第十一食堂内部模型

入口 `?floor=v-1112-f1`，位于十一十二食堂建筑的一层。默认俯视图，可切换三维、旋转缩放；初始横向展示、右侧为北。室内局部坐标 +X 指北、+Z 指向柜台前通道，不作为校园经纬度。

## 照片和空间对应

原始照片位于项目上层 `十一 十二食堂/十一食堂/1.jpg` 至 `5.jpg`。用户确认由北向南为照片 1—5，模型从左（南）到右（北）为：

| 照片 | 主牌     | 实际窗口 | 售卖类别                                         |
| ---- | -------- | -------- | ------------------------------------------------ |
| 5    | 天天主食 | 1—4      | 早餐；猪脚饭／笼仔荷叶饭；泡面工坊；锅仔系列     |
| 4    | 秦淮食坊 | 5—8      | 金陵老卤面；鸭血粉丝汤／小笼包；金陵小吃；铁板饭 |
| 3    | 寻味江南 | 9—12     | 9、10 减脂套餐；11、12 学子套餐                  |
| 2    | 食尚湘味 | 13—16    | 普通饭菜、自选菜                                 |
| 1    | 靓汤佳肴 | 17—18    | 现点小炒，同一家、共用点选区域                   |

水饺超市参照第八食堂独立点选。按用户要求竖摆，长轴沿 Z，坐标、朝向和点选区域同步；3D 点击面高度限制为 1.3，避免截住后面窗口。冰柜标签面朝南，便于初始镜头查看。

18 个实际编号中，17、18 共用一个商户 ID；加上冰柜，共 18 个可点选记录。窗口位置由数据明确记录，不依赖列表顺序。详情使用组编号元数据显示“17、18 号窗口”。尺寸为照片比例示意，未经实测。

## 外观与细节

- 五种浅绿／米白印刷门头分别绘制书法风格文字、黄圆红字、金色卷轴、回纹、水墨和菜盘装饰。未套用十二食堂红色发光底板，也不复制大面积灯管反射。
- 9—18 下层使用黑底红色 LED 字，1—8 为分窗菜单牌。“学子套餐”使用连续字芯和细点阵，避免笔画丢失；2 号保留免费汤供应提示。
- 黑石台面、米白瓷砖裙墙、不锈钢框、透明玻璃、浅色横条吊顶、排风格栅。按用户复核保留中间四根白色柱子；各组柜台、牌匾、顶棚与白柱紧密相接，不留空隙，外两端保留墙体。
- 18 处内部暖黄光、汤锅、蒸笼、锅仔、铁板、小炒样盘、对讲器、麦克风、线缆及支付终端。
- 用户确认空着的自选菜窗口应仿照四、五食堂内部，复用其餐盘、热菜、备餐和蒸汽模块，不据此判断停业。
- 紫色透明滑盖冰柜含饺子袋和轮脚，南大后勤采用仓库原图；组间多层餐盘推架；黄色地滑牌为顶部收拢、底脚展开的 A 形，文字两面朝外。
- 不建人物。俯视只隐藏五组顶棚，保留内部暖光、器具和附件；后墙外标签避开模型并保持正常字形比例。

菜品装饰由程序绘制，原始顾客照片未打包。未录入无法保证实时有效的照片菜单价格。新模块不引入依赖。
