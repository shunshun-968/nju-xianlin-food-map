# 食堂建筑外观接入

本次基于最新主分支 `09fdfac`，接入独立预览中完成的四组建筑外观。只导入模型工厂、材质标牌及品牌矢量轮廓；没有移入独立站的 HTML、样式、侧栏、相机控制器、照片图库或开发工具。

## 接入方式

- 校园地图沿用当前网站的地图坐标与场所选择；点击场所后，原 `MapScene` 建筑层按需加载对应外观。其他场所保留原来的场景。
- 楼层卡片、面包屑、浏览器返回、缩放、平移、旋转和手机抽屉均沿用当前网站。模型入口点击调用现有 `onPick('floor', floorId)`，进入同事刚更新的室内模型。
- 三维取景根据模型投影范围及现有侧栏／导航的可用空间计算。只增加与既有说明文字同样样式的“点击入口或选择楼层进入”提示。
- 建筑外观允许从俯视降低到平视（极角 `0–π/2`），方便看进第九食堂等深门廊；观察第九食堂时还可转向南面，减少侧墙遮挡。水平边界限制的是相对观察中心的旋转，平移仍沿用原有操作。
- 入口选择先检查最近可见表面，不允许穿过外墙点击背面的门。退出外观时调用模型自己的 `dispose()`，释放几何、材质、文字遮罩和纹理；延迟加载期间切换页面不会挂入旧场景。
- 21 个入口均设有跟随三维位置的可点击标记，沿用网站紫色配色。编号代表食堂，民族与教工分别显示“民”“教”；悬停或键盘聚焦展示完整入口名称。与独立预览一致，背向当前镜头的标记隐藏，旋转后显示；进入室内时清除这层标记。
- 白天保留原来的玻璃与建筑辨识色；夜晚采用冷色环境光、暖色透窗光和门厅补光，随网站昼夜开关即时切换。建筑模块按需分包；没有新增依赖或远程图片请求。

## 夜间照明

- 四组工厂通过材质的 `userData.exteriorLighting` 明确标出立面窗与玻璃门；使用稳定的 `exteriorLightVariant` 保留暖白、浅琥珀和少量冷暗窗的差异。栏杆、水平雨棚、屋顶采光顶及幕墙实心带不作为室内发光窗。
- `src/lib/exterior-lighting.ts` 统一管理夜景：一张共享的程序透光纹理表现上亮下暗、灯槽和轻微家具剪影，避免整块玻璃同亮。切回白天恢复原来的颜色、自发光、纹理、粗糙度、金属度及环境反射强度。
- 每个入口有一条暖白灯槽和一盏有限照射距离的点光源，照亮门厅、近处立面和台阶。灯具按原入口组的坐标与标高布置，适配四五六模型的整体旋转以及半地下、平台入口；每栋仅 4–7 盏无阴影灯，窗口不逐一增加实时灯源。
- 夜间降低环境贴图、半球光与主光强度，让窗光成为视觉重点，同时保留建筑轮廓。照明附件不参与入口射线拾取；切换主题复用对象，退出建筑时统一释放新增纹理、材质、几何与灯光。

## 保留的用户确认

- 第四食堂三个入口均下半层进入。
- 民族食堂西门的楼梯在建筑轮廓内部，左侧较宽楼梯、中间红柱、右侧不可通行白墙；南西两门同层。南廊下方的实墙与凹口关系保留。
- 八九食堂东侧上下牌依次为汉堡王与必胜客，保留用户提供的标志字形；两品牌只是立面标识，不新增食堂入口。
- 第十一食堂北门下半层，东门远处下约 0.2 层缓坡、坡后平地进入，南门平层进入。路径高差仍为示意比例。
- 四组屋顶均为简化模型；尺寸未测绘，不声称建筑细部为实测。

## 来源与维护

几何来自本地独立项目 `canteen-456-exterior-lab/src`，`building.js` 在正式项目中改名为 `fourth-fifth-sixth.js`，其余模型和辅助模块保持来源内容。原始拍摄照片、临时参考图和独立预览文件没有复制到正式网站。

`commercial-sign-data.js` 保留实拍字形轮廓，`east-brand-plaque-data.js` 保留用户补充品牌图片的轮廓；运行时使用 Three.js 几何，不加载照片背景。标牌仍保留现场文字与配色。

回归测试 `tests/exterior-buildings.test.ts` 使用实际 Three.js 几何验证四栋夜景、21 个入口的目录映射和遮挡选择、日间材质恢复、昼夜画幅稳定、反复切换资源复用及资源释放。原有室内、目录、导航与校园地图测试继续运行。
