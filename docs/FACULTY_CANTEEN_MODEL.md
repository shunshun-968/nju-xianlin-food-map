## 表现与资料边界

- 还原浅木色竖纹柜裙、不锈钢台面、玻璃分隔、浅色瓷砖后厨，并依窗口配置菜盆、汤锅、煮面设备、炒锅、排烟罩和轻食陈列。
- 2、3、4 号的矩形菜盘长轴沿柜台前后方向摆放，菜品随盘转向，菜牌仍面向顾客。柜台只向厨房侧加深承托两排菜盘，售餐前沿与窗口点击范围保持一致。
- 售餐台使用参考十二食堂的低位暖黄灯（`#ffcc7b`），分段照亮菜盆，兼容既有窗口选择聚光和日夜模式。
- 灯箱使用照片中的配色与字形类别：轻食绿白、午晚餐红白黄、普通饭菜黑底红字与金色装饰、面坊白红、汤品白金、明档紫色菜单。文字与图案为模型内 Canvas 图文；“南大后勤”标识引用仓库原图并保持比例。
- 模糊的小字菜名、价格不猜录；菜品列表留空，未把拍摄当日的价目表或值班时间当作实时数据。清楚的午晚餐和特色服务信息保存在 `facultyServiceNotes` 以便后续维护。
- 各编号独立点选；没有把售卖同类菜品的窗口擅自合并为一家。
