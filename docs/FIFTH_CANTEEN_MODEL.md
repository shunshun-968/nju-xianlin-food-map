# 第五食堂窗口模型

入口为校园 → 四五六食堂 → 第五食堂（`v-456-f2`），直达参数为 `?floor=v-456-f2`。默认俯视揭顶，使用同一个室内模型切换 3D；两种模式均可直接滚轮放大查看，不增加近景或漫游模式。

模型依据工作区 `四五六食堂/五食堂/1.jpg…8.jpg` 及用户确认的位置关系建模。窗口数量、牌坊文字与号码按参考资料保留，尺寸和进深采用便于浏览的比例，**并非实测尺寸**。

## 外向凸角与同店两面

默认俯视以 +X 为屏幕右方、−Z 为屏幕上方。长排从左向右依次是南粥北面、味道作坊、巧厨天地、香積八方、家常味道、石城滋味；左侧短排从下向上是手工·水饺、五味杂陈。长排朝屏幕下方（+Z）开窗，短排朝左方（−X）开窗，厨房分别向 −Z 和 +X 延伸。

南粥北面的 15、16 号窗口与手工·水饺的 17、18 号窗口属于**同一家转角店铺**，共享 `shopId=nanzhou-shuijiao`。两个牌坊形成 90° 外凸角，没有斜切墙、斜面窗口或额外店铺。其余店铺使用 1—14、19—21 号窗口。

`FIFTH_LAYOUT` 共用服务面偏移 1、厨房进深 3.5 的布局约定。转角为 `(-17.5, 7.3)`，同店厨房边界为 X `[-17.5, -14]`、Z `[3.8, 7.3]`；两面服务前沿在该角点相接，厨房体块只创建一次。不同牌坊仍保留独立 `faceId` 和独立窗口选择目标。

## 材质、花格与营业氛围

第五食堂使用自己的花格灯箱、立体书写字和配色，不复用第四食堂的区域风味招牌样式。各店通过不同花格密度、底板和字色区分：石城滋味使用棕色格纹与金色字，家常味道使用红色中央底板与浅色字，味道作坊保留棕色底板与红字；巧厨天地使用偏棕的格纹，香積八方与南粥北面采用深色格纹和红字，手工·水饺采用较密的方格，五味杂陈采用菱格、深色字底与浅色字。牌坊两侧保留各自的简化装饰，文字以确认的汉字为准。

前柜采用木色柜门、程序生成的木纹、不锈钢操作面与台下暖色灯带。厨房保留完整进深、备餐台、锅具、盘碗、简化热食、收款设备与少量工作人员，配合窗口暖光和轻微蒸汽呈现营业气息。食物和装饰图形用于表达形态，不作为真实菜单、价格或在售情况的证据。

俯视模式只揭去屋顶、增加便于阅读的牌坊与窗号标签，保留实际厨房、柜台和营业细节；3D 模式恢复屋顶并允许旋转。直接缩放以指针位置为中心，最大缩放为 14。切换 UI 白天／夜晚仅调整外围背景与底座，店内暖光、菜品形态、人员和几何布局保持不变，也不因主题切换重置相机。

## 实现与展示边界

- `src/data/fifth-canteen.ts` 提供牌坊、实际窗号、稳定 ID 和位置数据；`src/data/indoor-canteens.ts` 通过第五食堂的 spec 接入主站三级导航。
- `FourthCanteenModel.ts` 中的公共 `createCanteenModel(spec)` 按 `shopId` 去重店铺空间；第五食堂使用 `style: 'fifth'` 和 `fifth-canteen-signage.ts` 生成专属花格招牌。
- 网页不展示任何实拍图片，窗口详情只显示牌坊名、食堂名与实际窗号。源照片保留用于建模参考，不在详情、弹窗或轮播中加载。
- 不编造菜名、价格、评分或评价；第五食堂 Catalog 的 `dishes` 为空、`photoKey` 为 `null`。
- 不改动其他场所的模型、校园底图或已有主站昼夜主题。
