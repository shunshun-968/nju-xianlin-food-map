# 第四食堂窗口模型

入口为校园 → 四五六食堂 → 第四食堂 (`v-456-f1`)。本地直达 `?floor=v-456-f1`，默认俯视揭顶，可切换 3D。两种模式共用同一个室内模型。其他楼层仍保留既有示例内容。

按实拍照片进行结构与材质的写实化建模，保留窗口数量、分隔、牌坊文字、完整店铺进深和相对位置。店铺包含厚实屋顶、砖墙、不锈钢柜台与窗框、上部玻璃和下部取餐开口；店内备餐台、餐盘、热食、工作人员与暖光让场景呈现营业中的生活气息。可直接滚轮放大查看窗口与室内细节。尺寸是便于浏览的示意比例，并非实测。

## 俯视与营业场景

默认俯视保留每家店铺 3.5 单位的完整进深，呈现有宽度和纵深的厨房体块。俯视仅隐藏屋顶和吊顶，增加横向可读的牌坊名称与窗口编号；柜台、厨房、设备、热食和工作人员继续使用 3D 模式中的同一组几何。切回 3D 时恢复屋顶，观察位置转到左下外侧，可以直接看到两排朝外开设的窗口。

备餐区包含操作台、蒸锅或汤锅、电饭锅、叠放的盘碗、调味瓶和收款设备。前柜摆放少量不锈钢餐盘与简化的热食形状，保留取餐和收款位置。食物只提供形态与颜色提示，不据此补造真实菜名、菜单或价格。

少量店铺内设置自然比例的工作人员，脚底落在厨房地面，穿浅帽、深色工作服和围裙，以弯臂托盘或持勺的姿态面向服务窗口。人物没有精细五官，避免抢夺牌坊文字和窗口结构的视觉重点。

室内使用暖色环境与窗口局部暖光，柜台上方设置保温灯带、小型金属保温灯与灯芯光晕。3D 模式加强照向热菜的暖光，俯视保留较柔和的照明以避免台面过曝；亮度不随 UI 昼夜主题改变。锅具上方有轻微上升、渐隐的蒸汽，帮助表达热食状态；系统启用减少动态效果时停止蒸汽动画。室内始终保持同一营业状态。

招牌由 `fourth-canteen-signage.ts` 生成，使用原照片裁切、透视校正后的 13 块主牌匾与 13 条下方灯箱纹理。保留实际字形、品牌、山水插画与色彩，模型补充金属包边、压条和固定螺丝。俯视辅助牌匾复用相同照片纹理；共享转角保留单一文字标识，避免两块牌面交叉遮挡。照片灯箱只用于还原现场装饰，不据此生成当前菜品或价格数据。

实拍白底已有照明和部分过曝，牌面采用 `MeshBasicMaterial`、关闭 tone mapping，并以中性灰限制最高显示亮度（主牌面 `#dededb`，下方灯箱 `#d7d7d3`）。它不会再叠加环境光、点光源或自发光；金属框仍使用物理材质参与灯光与阴影。这样减轻模型中的泛白，同时保持不同 UI 主题下文字颜色稳定。照片已经完全截白的细节不会被伪造补画。

浏览前先加载并解码全部局部贴图，再构建模型；并发加载共用一次请求，失败的资源可重试。CPU 图片可复用，每个模型拥有自己的 GPU 纹理并按现有生命周期释放。

## 外向凸角与店铺进深

按用户最新参考图，左下角为凸转角。长排窗口朝屏幕下方（+Z），短排窗口朝屏幕左侧（−X）；厨房在窗口后方，分别向 −Z 与 +X 延伸。方向由模型本身的开口法线决定，不能通过转动相机掩盖相反的开窗方向。3D 初始视角从左下外侧观察两排服务面，默认俯视仍保持原照片的位置关系。

`FOURTH_LAYOUT` 统一服务面偏移 `frontOffset=1`、厨房进深 `kitchenDepth=3.5`、外凸角点 `(-17.5, 7.3)`。主排牌坊中心的 Z 为 6.3、旋转为 0；短排中心的 X 为 −16.5，Z 依次为 5.55、2.05、−1.45，旋转为 −π/2。

麦金地的两块牌坊共享 `shopId=maijindi`，共同厨房边界为 X `[-17.5, -14]`、Z `[3.8, 7.3]`。这一个 3.5 × 3.5 的店铺同时拥有东侧两窗与南侧一窗，两个牌坊在外凸角精确相接；模型仅创建一次厨房体块，避免留空或叠放两个店铺。每个服务窗口仍使用独立窗口 ID。

`fourthKitchenBounds(face)` 从服务前沿与向后的进深计算真实世界边界。Catalog 窗口位置取厨房中心：局部 Z 为 `1 - 3.5/2 = -0.75`，再按牌坊旋转映射到世界坐标；不能直接将牌坊中心误作厨房中心。

## 实现边界

- `data/fourth-canteen.ts` 是牌坊与窗口的共同数据源，俯视和 3D 共享同一位置、宽度、数量、开口方向和厨房边界。
- `FourthCanteenModel.ts` 中的公共 `createCanteenModel(spec)` 统一柜台、窗口上沿、牌坊顶底高度，按 `shopId` 创建厨房；第四食堂通过自身 spec 保留麦金地外凸角与完整店铺空间。模式切换仅控制屋顶与辅助标签的可见性，不替换厨房为独立平面图。
- `fourth-canteen-details.ts` 生成备餐设备、餐盘、简化热食与蒸汽；`fourth-canteen-people.ts` 生成少量工作人员。厨房细节与暖光同时保留在俯视和 3D 模式中。
- `MapScene.tsx` 仅保留俯视与 3D 两种模式，初入此楼层默认俯视揭顶；俯视禁用旋转但保留平移缩放；按钮切到 3D 才开启旋转。查看细节直接在当前模式中滚轮放大，缩放以指针位置为中心，最大缩放为 14，不增加独立近景或漫游模式。
- UI 白天/夜晚仅改变外围背景与底座色，室内模型、文字、开口、照明保持一致，也不重置用户视角。
- 点击窗口继续使用主站详情面板展示牌坊名称、食堂名与窗号。网页只在模型牌匾上使用裁切后的招牌纹理，不发布包含人物的完整参考照片，不将装饰纹理作为窗口实拍或菜品数据。场景中的热食几何不生成菜品、价格或评价数据。
- 本次保留已有未提交的主站昼夜主题改动，没有改变其他场所模型。

回归测试验证长边 +Z / 短边 −X 的外向法线、前后壁关系、两牌坊前沿在凸角相接、麦金地共享厨房、24 个服务窗口及独立 ID、照片顺序、厨房与 Catalog 的边界一致且均位于楼层内。测试不通过相机位置推断开口方向。
