# 本地模型集成与性能调整

主项目：`nju-xianlin-food-map`。本次仅修改本地文件，未提交或推送 GitHub。

- 南门餐车原始几何与食品已纳入 `src/models/south-gate`，由 `SouthGateCartModel.ts` 接入主网站。使用现有导航、侧栏、缩放/旋转工具和顶部昼夜按钮；昼夜食品沿用原模型。
- 第四、第五、第六食堂分别位于 `?floor=v-456-f1`、`f2`、`f3`。默认俯视，支持 3D 和直接缩放。餐车直达为 `?venue=v-south`。
- 夜间灯光封装成自包含 SVG 矢量图层，保留原灯光数量、坐标、渐变和裁剪；无位图降采样。
- 模型合并仅处理普通不透明静态网格，保留点选 ID、材质属性与屋顶/俯视可见性边界。实例食物、透明物件、动画和可变底座保持独立。
- 重要回归：实例化食物不能作为普通 Mesh 合并，否则实例矩阵会丢失。测试现在检查每个实例的矩阵与实例数量。
- 模型在当前 3D 场景生命周期内缓存，返回建筑后再次进入复用；异步编译着色器时显示加载提示。静态阴影仅在场景、模式、昼夜改变时重算；保留原分辨率与软阴影。

验证：74 项测试通过；TypeScript 与 Vite 构建通过。三个食堂的三角面、边界、灯光、点选 ID 与食物实例矩阵一致；网格对象由 2936/2368/2157 减至 524/456/402。当前机器第四食堂首次准备 961ms，再次进入命中缓存为 10ms；这是一次本地测量，非所有设备保证，也不等同于帧率。
