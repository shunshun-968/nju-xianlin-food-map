## 桌面鼠标与导航

- 所有建筑、餐车和楼层共用 `src/lib/model-mouse-controls.ts`：在模型画布上单击右键进入或退出旋转模式，模式内不按键移动鼠标旋转，按住左键临时平移，松开后继续旋转，滚轮始终可缩放。旋转模式内的左键不会误选窗口。
- 俯视图保持不可旋转，先切换到 3D 模式。鼠标移入 UI 或离开画布暂停旋转，返回画布不跳转。Esc、窗口失焦、页面隐藏、切换模型、切换俯视／3D 和复位均清理模式；退出旋转后再按 Esc，沿用原有返回上级功能。触屏保持现有手势。
- 采用右键单击是为了避免持续按住右键移动，从操作方式上避开 Edge 鼠标手势；网页不修改浏览器设置，也不申请鼠标锁定权限。
- 桌面路径导航固定在右上方，为左侧栏和模型模式按钮留出空间；窄桌面下可水平滚动查看完整路径。移动端继续使用底部抽屉布局。
