# 地图交互性能定位与优化（2026-10-22）

基线提交 `4d7e735`；使用生产构建、同一 Chromium 会话、4 倍 CPU 限速进行对照。手机视窗 390×844，先缩小至 0.75 倍并完成外围预取，再模拟单指拖动与双指缩放；电脑视窗 1440×1000，连续开关顶部导航四次。实际手机的 GPU、内存和浏览器不同，以下不是手机实机帧率保证。

## 定位结果

- 地理坐标投影和基础 SVG 路径已离线生成，交互没有重新把 GeoJSON 转成路径。DOM 中 `d` 的变化主要来自屏幕标注引线和可见区域切换。
- 原实现虽给内部 SVG `<g>` 设置 CSS transform，但仍每帧 `setTransform`。可见窗口跨过 64 米网格时，重新筛选图形并协调大量节点；每次更新也重新布局标注。一次拖动记录 47 次 React 根提交和 6,366 次子节点变更记录。
- 同一地物被同时放入校内、校外裁切图层；大量明显不在校内的图形仍生成了不可见的校内副本。校外建筑还有逐栋阴影与轮廓节点。
- 顶部导航状态让父组件更新，并发送覆盖区事件；原来覆盖区事件也调用地图运动更新。侧栏、指北针、层级文字的 `top` 动画则反复产生布局。

## 实施顺序

1. 地图组件增加 memo；覆盖区变化仅更新标注，不启动地图缩放/平移。全景未达到名称门槛时，跳过建筑名称排序与道路名称扫描。
2. 手势中仅通过 requestAnimationFrame 移动 **SVG 根视口**，让浏览器合成缓存表面；不再逐帧协调 React 场景。手指离开且静止 160ms 后恢复原生矢量绘制、屏幕字号及精确标注。使用稳定容器坐标计算触点，避免 CSS 缩放改变事件坐标系。
3. 使用 180 屏幕像素（至少 100 米）的预绘制边缘。长拖动超过 140 像素，或缩放比例超出 0.7–1.45 时刷新场景，防止移出缓存区域；手势未结束时不因设备慢、事件间隔大就反复“收尾”。预绘制范围过大的试验增加了绘图负担，已撤掉。
4. 相邻同线宽、同类型道路合为复合 path，保持原绘制顺序。校外建筑按空间块分组，只有包络留有安全间隙的建筑可以共享 even-odd path；重叠建筑分别绘制，避免互相挖空。校园建筑仍单独保留，所有原始坐标、闭环和内院环都不改动。
5. 校内裁切副本只收录包络可能与校园范围相交的地物，保留跨界道路。复合路径只在可见窗口或数据改变时生成并缓存。
6. 电脑侧栏、指北针和文字改用 `translate` 动画。侧栏高度仅在状态切换时调整一次，保持动画两端的原位置和底部对齐。左右拖动与纵向移动独立，保留减少动态效果设置。

目前无需进一步删减远景地物或简化原始几何，也未增加 Canvas/WebGL 框架。原有按缩放出现的名称和林地纹理规则继续使用。移动过程中文字跟随缓存表面短暂缩放，停止后恢复正常字号和清晰度。

## 同脚本代表性对照（优化后重复两次）

| 场景 / 指标                  |  修改前 |      修改后 |
| ---------------------------- | ------: | ----------: |
| 手机拖动：React 根提交       |      47 |           1 |
| 手机拖动：SVG 子节点变更记录 |   6,366 |           0 |
| 手机拖动：场景 path 数       |   6,038 |       2,896 |
| 手机拖动：帧间隔 P95         | 230.8ms | 36.2–36.4ms |
| 手机双指缩放：React 根提交   |      51 |           4 |
| 手机双指缩放：帧间隔 P95     | 218.2ms | 51.6–55.0ms |
| 电脑顶部导航：帧间隔 P95     | 115.3ms | 18.1–24.2ms |

P95 为 95% 采样帧间隔不超过的值，越低越好。通过 rAF 采样、React DevTools 提交钩子、MutationObserver 和 CDP Performance 指标记录；测试工具本身也有开销。连续同样数量的触控事件在慢设备上执行时间会变长，因此不把各轮总耗时直接解释成真实用户操作时长。顶部导航仍有正常 UI 状态提交，但地图路径和子节点不变；少量首次合成/最终重绘的长帧仍存在。

## 回归检查与复测

- 37 项自动测试通过，包括道路绘制顺序、所有建筑环精确保留、重叠建筑不发生 even-odd 抵消，以及原有地图标注和数据检查。
- 浏览器模拟 240×48 像素拖动，最终位移误差小于 0.001 像素；双指缩放锚点误差小于 0.001 像素。
- 检查手机远景/近景截图、停止后的矢量恢复、外围解锁、食堂和楼层导航、Esc 返回、电脑侧栏开关和上下移动。
- 仅改变桌面动画实现，手机 UI 样式未改动；地图原始文件、已审核点位、加载分块与缓存版本均未变。
