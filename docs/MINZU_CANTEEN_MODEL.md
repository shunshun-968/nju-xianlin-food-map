# 民族食堂内部模型

入口为校园 → 民族食堂 八九食堂 → 民族食堂，直达参数 `?floor=v-891-f1`。沿用现有楼层作为技术入口，外部建筑和实际楼层对应后续校准。默认俯视揭顶，手动切换 3D，关闭窗口详情保留当前视角。

依据用户提供的 `民族食堂内部/1.jpg` 至 `4.jpg` 建模，`非精细图纸.jpg` 只用于位置与售卖关系校正。尺寸为示意比例，未画区域留空。

## 原照片字形

四块主牌匾使用现场照片区域的透视校正纹理，保留真实字形、配色、描边、装饰和反光，不使用统一字体替换，不将整张现场照片贴成店铺立面。牌匾按纹理比例设置高度，避免挤压字体。柜台、白色瓷砖、玻璃、银色框架、厨房和红灯笼为三维几何。

- 回味无穷·兰州拉面：蓝底浅色字，保留伊真味餐饮图案及面碗。
- 美食排档：紫底浅色行书、花角与星光。
- 民族风味：深紫底浅色行书、两侧菜品图。
- 边陲风情：蓝绿色背景、深蓝色浅描边行书。
- 学子特价套餐窗口与暖心早餐：采用原照片中无遮挡的文字区域；暖心早餐完整心形牌被人物遮挡，模型只复用清晰可见文字，不补造被挡内容。

来源、提取坐标和离线复现方法见 `src/assets/minzu-canteen/README.md` 及 `scripts/models/prepare-minzu-signs.py`。原始带顾客的全景照片不进入网页资源；纹理是牌匾装饰，不用作当前菜单、价格或菜品信息。

## 窗口、牌匾与售卖

照片共有 1—10 号窗口，1、2 号印在蓝色电子菜单屏内，3—10 号为紫色号牌。每个窗口保留独立 ID、坐标和点击范围。牌匾边界单独存于 `minzuSignBoards`，不能按窗口数组数量推算。

| 真实窗口号 | 实际售卖                   | 对应主牌匾                      |
| ---------- | -------------------------- | ------------------------------- |
| 1          | 拉面、刀削面、炒面、炒米粉 | 回味无穷·兰州拉面               |
| 2          | 脆皮鸡排饭                 | 回味无穷·兰州拉面               |
| 3          | 学子特价套餐               | 横跨回味无穷·兰州拉面、美食排档 |
| 4          | 麻辣烫                     | 美食排档                        |
| 5          | 暂无售卖                   | 横跨美食排档、民族风味          |
| 6          | 拌面、盖饭、水饺           | 民族风味                        |
| 7          | 暂无售卖                   | 民族风味                        |
| 8、9、10   | 自选菜，三个窗口均可购买   | 边陲风情                        |

用户明确确认 3、5 号各横跨两块主牌匾；没有额外未编号窗口。示意模型把相邻牌匾的接缝放在这两个窗口中点，各自宽度与柜台分隔独立。5、7 号保留完整柜台，不填入虚构餐食或工作人员。

南侧自选菜按用户说明分成两个等宽展示区，每区覆盖 1.5 个窗口，标注放在各区中央。**这不是两个可点击的大窗口，也不是 8＋9 与 10 的店铺合并关系**；8、9、10 三个独立窗口均可购买两区自选菜。`minzuSelfSelectAreas` 保存展示区范围及可购买窗口号，不推断经营主体是否相同。

## 早餐地点记录

8 号的“暖心早餐”是需要长期保留的真实挂牌。目录中 `v-891-f1-bianchui-w1` 保存 `breakfast: true`，类型见 `Stall.breakfast`，并随 `npm run data:export` 写入 `data/demo-catalog.json`。页面列表与详情显示该地点供应早餐。

以后实现“只看早餐地点”时，可用 `stall.breakfast === true` 筛选。其他窗口省略该字段表示情况未知，不能当成已确认不卖早餐。当前没有可靠的早餐菜单、价格和营业时间，所以不填写。此字段目前保存在静态目录；将来改用数据库目录时，应同步扩展数据库读写契约，避免服务信息丢失。

## 空间约定与验证

北向上，`+X` 为东、`−Z` 为北。西侧 1—7 号由北向南排列，向西售餐；南侧 8—10 号由西向东排列，向南售餐。两排服务边分别为 `x=-5` 与 `z=8.5`。未采集的桌椅、门窗及其他区域留空。

测试覆盖真实号牌、跨牌匾映射、两组自选菜展示区、早餐标记、空窗口、转角朝向、牌匾原图比例、点击范围和视图切换。民族食堂招牌较高，点击面单独覆盖到 4.5；其他食堂与第八食堂冰柜沿用原有点击高度。
