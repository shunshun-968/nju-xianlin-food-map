# 模型指北针与方向依据

建筑外观、食堂内部及餐车共用 `ModelCompass` 圆盘，延续网站暖纸／紫色与夜晚配色。默认位于导航、视图切换下方；拖动圆盘可改变屏幕位置，双击或按 Home 归位，方向键微调（Shift 加大步长）。只在圆盘区域接管指针，不带动背景模型。校园总平面原有的静态指北针保留。

圆盘每帧读取相机的水平右方向，将模型真实北向转换为屏幕角度。普通视角按水平屋顶的投影缩短圆盘纵轴：纵向比例为相机仰角的正弦，圆盘与屋顶保持平行。方位字母跟随圆盘上的投影位置移动，自身保持直立，不随平面压扁。平移、缩放和屏幕宽高不会扭曲方位，没有额外 React 逐帧渲染或 CSS 跨 360° 的旋转补间。

接近平视时，水平面会退化为一条线。仰角从 18° 降至 8° 的过程中，圆盘通过 smoothstep 平滑过渡为正面显示，并出现“平视指北”提示；8° 以下完整朝向屏幕，仍跟随模型方位旋转。过渡没有突跳，不会看不到指针或让方位字母挤在一起。

拖动位置保留到后续模型／楼层切换；视口尺寸、顶部导航或侧栏改变时，位置限制在可用区域内，避免拖出屏幕或落入手机抽屉。切换界面配色不会重置位置。这里的指针拖动只移动控件，模型旋转继续沿用原来的鼠标及触摸手势。

设计参考 Autodesk [ViewCube 的方位反馈与 Compass](https://help.autodesk.com/cloudhelp/2024/ENU/Revit-DocumentPresent/files/GUID-787A15B5-773E-4385-A765-7889D1C64475.htm)。屋顶平面投影、可移动悬浮位置和临近平视的适应显示是本网站的实现，没有引入额外控件库。

方向集中在 `src/data/model-orientation.ts`，以下均为最终模型的世界坐标，不是模型旋转前的内部坐标：

| 模型 | 北向 `(x,z)` | 依据 |
| --- | --- | --- |
| 四组建筑外观 | `(0,-1)` | 原独立站已校正世界朝向；四五六根组已经旋转，不重复变换 |
| 第四食堂内部 | `(1,0)` | 原建模记录：南向左 |
| 第五、第六食堂内部 | `(1,0)` | 用户于 2026-10-26 确认默认俯视右侧为北 |
| 民族、第八、第九食堂内部 | `(0,-1)` | 各食堂建模记录及手绘方向 |
| 第十、教工食堂内部 | `(-1,0)` | 第十模型布局注释、教工手绘图：左侧为北 |
| 第十一、第十二食堂内部 | `(1,0)` | 原建模记录：右侧为北 |
| 南门餐车 | `(0,-1)` | 用户于 2026-10-26 确认售卖正面朝南，模型售卖面为 +Z |

美食小屋和逸夫售卖点目前仍是通用示例几何，缺少可核实朝向，显示“朝向待核实”的方位盘，不伪造北向。后续完成实际建模后只需补充方向数据。
