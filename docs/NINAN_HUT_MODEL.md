# 呢喃小屋外观与餐段切换

呢喃小屋位于四五六食堂东侧。校园地图与列表统一显示「呢喃小屋」，原有地理坐标和地点 ID `v-hut` 保持不变，因此已有链接仍可使用。

## 打开与操作

在仓库目录运行 `npm run dev`，打开终端显示的地址并加上 `?venue=v-hut`。默认开发地址为：

<http://127.0.0.1:5173/nju-xianlin-food-map/?venue=v-hut>

直接打开看板可使用：

<http://127.0.0.1:5173/nju-xianlin-food-map/?venue=v-hut&stall=v-hut-f1-service>

- 点击校园地图中的呢喃小屋，直接进入建筑外观；这里没有楼层或室内进入按钮。
- 桌面端拖动平移、滚轮缩放；单击右键进入旋转模式，再次右键或按 Esc 退出。触屏使用双指缩放和旋转。
- 点击空间中的「小屋详情」提示按钮打开看板。左侧「打开小屋详情看板」也可打开同一看板。
- 场景控制区和看板内都有早餐、午餐、晚餐选择；任一处切换，另一处与模型同时更新。切换餐段和开关看板保留当前观察角度与缩放。
- 白天进入默认早餐，夜晚进入默认晚餐；在小屋内切换日夜主题时，餐段也回到对应默认值。之后仍可手动选择其他餐段。

晚餐模式按照片 10–13 展示「油炸烧烤」门面外的鲜食柜和白色小棚下的烧烤架。小屋内部的饮料机仍保留。详情看板使用夜间实拍，不补写未提供的烧烤菜单与价格。

## 餐段与数据

| 餐段             | 当前表现                                                 |
| ---------------- | -------------------------------------------------------- |
| 早餐 `breakfast` | 白棚下早餐售卖场景与早餐详情，早餐牌保持真实位置         |
| 午餐 `lunch`     | 北侧咖啡饮品窗口的饮品设备与原料，展示饮品实拍和参考价格 |
| 晚餐 `dinner`    | 门面外鲜食柜、白棚下烧烤架与夜间实拍；屋内饮料机继续保留 |

数据保持一个场所、一个服务点：场所为 `v-hut`，服务点为 `v-hut-f1-service`。`v-hut-f1` 仅作为目录数据中服务点的归属容器，不代表可进入的室内楼层；旧楼层链接会转到外观。主窗口和早餐棚分别保存局部空间坐标，位置不依赖菜单或数组中的排列顺序。

`App.tsx` 保存唯一的餐段状态；场景模型通过 `setMealMode` 显示对应陈设，看板读取同一个值。日夜照明通过 `setInterfaceTheme` 单独设置，便于夜间查看早餐、白天查看晚餐陈设。切换不会重新创建整个场景。晚餐模式保留午间的室内饮品设备，另加鲜食柜与棚下烧烤设备。

## 维护入口

- `src/components/NinanHutModel.ts`：外形、材质、陈设分组、照明及空间提示坐标。
- `src/data/ninan-hut.ts`：服务点身份、空间位置、餐段类型与默认餐段。
- `src/components/NinanHutDetails.tsx`：共享餐段选择与看板内容。
- `src/components/MapScene.tsx`：模型接入、观察视角和跟随空间位置的提示按钮。
- `src/assets/ninan-hut/`：随网站打包的实拍 WebP；原始来源与压缩参数见该目录的 [README](../src/assets/ninan-hut/README.md)。

所有照片以模块资源 URL 引用，不依赖开发机路径，可随 GitHub Pages 子路径或其他域名部署。价目牌使用现场照片，详情只摘录清晰可辨的部分商品及价格；价格以现场公示为准。南京大学校徽及南大后勤标识沿用仓库已有原图。

### 牌架间距校正

按照片 6 和用户标注，字牌、海报与彩色座椅整组移到咖啡饮品窗口以西，靠近露台西端，同时向北离开屋体。整组最近处与伸出的遮阳棚保留约 0.6 米模型间距，吧椅旁留出通道；同步扩展其下的木平台，将黑色桌椅移到台阶外的石铺地。尺寸为照片比例估算。几何回归检查覆盖棚布、吧椅、花箱、遮阳伞与平台边界，检查使用合批后的实体网格。

场景右上角仅保留早、午、晚餐切换按钮，不再显示餐段说明标签与自动旋转按钮；侧栏和场景中的冗余引导文字已移除。
