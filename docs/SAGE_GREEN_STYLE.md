# 鼠尾草绿与分级林地纹理

本轮基线为 `35f6e6f`。原图的偏黄与云团来自两层：林地填色 `#C9D5A9`，以及 `CampusGreenRelief` 叠加的高程色带 `#B4C69C → #C6D3AA → #DBE0B7`、平滑 DEM 坡面明暗。默认视图现在停用该栅格叠加，采用平面块色。原始 DEM、既有地物坐标、历史成果与重建脚本保留，前端不请求地形色带、树木模型或等高线。

## 图层规则

| OSM 地物属性                                                  | 校内      | 校外      |
| ------------------------------------------------------------- | --------- | --------- |
| natural=wood / landuse=forest                                 | `#C7D4BD` | `#DCE3D6` |
| grass / grassland / meadow                                    | `#E6EBD9` | `#E8ECE2` |
| scrub / garden / park / recreation_ground，以及其他未细分绿地 | `#DCE5D1` | `#E3E8DE` |

校园暖纸色、建筑、车道与场所标记沿用原样。校外基底为 `#E3E8DE`，居住/商业地块使用相近的中性灰绿；只调整实际填色，没有整图白色蒙层。运动设施和校园内建设用地继续用原颜色。

原始地块路径不做平滑、移动或重画。绿地采用 SVG `geometricPrecision` 抗锯齿，不加边框或模糊光晕。校园步道从土黄色虚线改成连续暖白 `#F8F5E9`，宽度及中心线保持不变，校外道路规则保持不变。

## 林地纹理

纹理只用于校园内原始 OSM 明确标记为 wood/forest、面积至少 10,000 平方米的四片林地：`way/118942393`、`way/118942396`、`way/448907845`、`way/448907870`。上一版第五片绿地为 recreation_ground，因此不画树冠。其他小片绿地和所有校外绿地不加纹理。

- 300 个固定树冠纹理，三个轻微不同的俯视轮廓，半径 3.8—6.2 米，中心间距至少 22 米。密度场留出疏密变化和空隙；这是林地图面纹理，不代表实测单株树木位置。
- 使用 `#A8BA9D`，无描边、树干、投影。小幅浅色冠内细节也处于低透明度组内。
- 初始倍率 1.2：不显示纹理。第一组在倍率 1.55—2.8 之间平滑渐显，最大不透明度 34%；第二组在 3.1—5.5 之间渐显，最大 28%。两组的坐标和所属级别预先保存，缩放不会重新抽样。
- 道路中心线外保留半路宽再加 7 米；建筑、水面、运动场外保留 9 米。林地内缩 4 米仅用于纹理安全区，不改变绿地填色边界；整个树冠包络必须在安全区内。
- 天文台和餐饮锚点额外留白。渲染时在现有标签外再避让 6 屏幕像素，并按视窗剔除不可见树冠，避免视觉干扰和不必要绘制。
- 图层使用复用 SVG 图形，`pointer-events:none`，不阻挡地图拖动或食堂入口。
- 拖动/缩放输入按显示帧合并；静态地物以带余量的 64 米网格视窗缓存 SVG 节点，固定树冠节点也缓存，仅修改整体相机变换、渐显透明度和必要的裁切/避让。无需每次指针事件都重新构建所有地物。

## 数据与验证

`scripts/osm/build-forest-texture.py` 从已保存的 OSM 生成 `public/osm/campus-forest-texture.json` 与 `campus-forest-mask.geojson`。每个地块使用固定种子，生成结果确定。输入哈希记录在 JSON 内。

```powershell
# 使用已安装的 Shapely，或按 requirements-basemap.txt 安装到 .cache/osm-build
npm run osm:build-forest
npm run osm:validate-forest
npm test
npm run build
```

验证脚本独立检查 OSM 林地属性、校园范围、完整树冠包络、道路/建筑/水面/运动场净距、最小间距及输入哈希。
