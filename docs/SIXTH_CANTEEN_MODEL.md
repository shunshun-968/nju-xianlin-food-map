# 第六食堂窗口模型

入口为校园 → 四五六食堂 → 第六食堂（`v-456-f3`），直达参数为 `?floor=v-456-f3`。默认俯视揭顶，可以切换 3D；在当前模式中直接滚轮放大查看窗口和厨房，不增加额外视角模式。

建模依据工作区 `四五六食堂/六食堂/1.jpg…10.jpg` 和用户确认的位置关系。尺寸、店铺宽度和进深采用示意比例，**不代表实测尺寸**。照片没有确认真实窗口编号，因此页面按左侧、中间、右侧及取餐口说明位置；数据 ID 中的 `-w1` 等局部序号不是实际号牌。

## 窗口立面、开口与屏幕

模型共 **11 个窗口立面区、8 个厨房空间、20 个实体窗口、23 块 LCD**。其中主排 8 个区域共 17 个窗口；金陵小厨侧面另有 1 个转角玻璃窗和 1 个取餐口；淮扬菜品侧面另有 1 个窗口。金陵小厨转角玻璃窗采用固定玻璃，仅呈现建筑与内部照明，数据中以 `displayOnly` 标识，不创建 Catalog 条目或点击选中状态；其余 **19 个窗口可选中**。页面不添加用途限制标注。

## 金陵小厨的长厨房

金陵小厨的主面、转角玻璃窗与侧取餐口共享 `shopId=jinling-kitchen` 和同一个长厨房空间，世界边界为 X `[-17.5, -12.25]`、Z `[-7.5, 7.3]`。主服务面位于 Z=7.3；左侧墙位于 X=−17.5，在 Z=5.5 处设置宽 1.75 的转角玻璃窗，在 Z=−4.5 处保留宽 1.75 的侧取餐口，其他侧墙连续封闭。

主面的三个服务窗口保留全高玻璃结构，不叠加普通开放柜台的低矮斜玻璃。侧取餐口只作为取餐通道，不增加大抽油烟罩。中后段设置不锈钢操作台、开放置物架、少量锅盘及工作人员；家具位于 Z≤2.2 的厨房内部，保留从侧取餐口进入的行走通道。前台、屋顶与墙体由主模型统一生成，室内家具函数不额外添加服务窗。

## LCD 文案

屏幕文字来自 `src/data/sixth-canteen.ts` 的 `screenTexts`。只显示用户确认的大字，不补造细小菜单、菜名清单或价格。

- 美食档口一块屏显示“麻辣香锅窗口／素菜15元/斤／荤菜32.5元/斤／晚餐销售”，其中 **15 元/斤、32.5 元/斤** 已由用户确认；另一块为“自选菜”。
- 百变窗口分别显示“贵州蘸水菜”和“自选减脂餐窗口”。
- 风味小吃分别显示“广式烧腊”和“自选菜”。
- 金陵小厨、中式面点、地方特色、天府菜肴、淮扬菜品及各侧窗、侧取餐口的其余屏幕显示“自选菜”。

这些文字作为确认后的场景内容保留，不据此生成实时菜单、价格服务或营业承诺。LCD 使用程序绘制的屏幕材质，不嵌入照片。

## 材质与营业细节

第六食堂使用白灰柜台、银色不锈钢操作面、黑边 LCD 与冷白屏幕。每个窗口内部均有黄色暖光，包括金陵小厨转角玻璃窗、侧取餐口和淮扬菜品侧窗，照亮食物、台面和内部空间。普通开放窗口采用低矮后倾玻璃挡板与细银色支架：柜台面约 Y=1.21，玻璃由 Y≈1.23、局部 Z≈0.99 倾至 Y≈1.72、Z≈0.55，不使用第五食堂的全高花格框架。

后厨每约 3.5 单位宽度设置一组大不锈钢抽油烟罩，壳体底约 Y=2.22、顶约 Y=2.65，带暗色滤网、排气条和金属前沿。少量白色悬挂线灯及吊线位于 Y≈2.4；五金补充模块只使用几何和材质，不额外创建实时点光源。锅具、餐盘、热食和工作人员继续由公共细节模块与金陵厨房补充模块安排，避免重复堆放。

## 实现与展示边界

- `src/data/sixth-canteen.ts` 是窗口数量、屏幕文案、照片区段和长厨房边界的来源；同一厨房的主面、侧窗与取餐口按 `shopId` 归并。固定转角玻璃窗保留在立面数据中，不进入 Catalog。
- 第六食堂使用独立的 `SixthCanteenModel.ts`，公共创建入口按 spec 派发对应模型，不将第五食堂招牌或木柜样式套到第六食堂。
- `sixth-canteen-details.ts` 提供开放柜台挡板、抽油烟罩与吊线灯；`addJinlingKitchen` 只补长厨房内部家具和工作人员，不修改墙面、窗口数量或屏幕数量。
- 默认俯视可查看真实店铺进深，切到 3D 后允许旋转；两种模式均直接缩放查看细节。
- UI 昼夜切换仅适配外围背景与底座，室内灯光、屏幕、餐品形态、人员和开口不随时段更换，也不重置视角。
- 所有网页均不展示实拍图片，源照片仅保留为建模参考；窗口详情使用区域名称与左右位置，不声称存在照片未确认的真实编号。
- 不编造菜单、评分或评价。除上述用户已确认的 LCD 文案外，不添加价格信息；Catalog 的 `dishes` 为空、`photoKey` 为 `null`。
