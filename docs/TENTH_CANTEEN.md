# 第十食堂内部模型

接入一层 `v-10-f1`，二层教工食堂维持原有入口与示意内容。模型来自本地独立版本 `tenth-canteen-3d`，保留其暖光、蒸汽、餐盘、垂直菜品台和原照片牌匾。

- `src/models/tenth-canteen/layout.js` 是窗口、柱子的坐标来源；数据目录与点击区域从相同坐标生成。左侧为北。
- 1—17 号对应真实编号；1—4 号合并为一个售餐区与一个俯视标签，5 号不显示俯视标签；16、17 号合并为一个经营档口，分别点餐、取餐。水饺超市独立点选。未确认主营的窗口留为待补充。
- 8—15 号的菜品台垂直于窗口；照片 5/6、7/8 之间没有柱子。北排 4/5 号之间柱子高度为 2.73，停在牌匾下方。
- 模型自身已合并静态网格，接入时跳过网站第二次批处理，保留可切换顶棚、灯光与动态蒸汽。网站负责窗口点选、卡片、聚光和相机控制。
- 牌匾使用原照片裁切、透视校正后的 WebP，保留原字形；南大后勤与校徽继续引用项目原图。页面不加载整组现场照片。

重建牌匾需 Python 和 Pillow：`python scripts/build-tenth-signs.py <包含1.jpg至9.jpg的照片目录>`。生成到 `src/assets/tenth-canteen/`。不需要修改或重新生成原独立模型。

窗口与射线匹配测试位于 `tests/tenth-canteen.test.ts`，覆盖俯视及三维的所有真实窗口，含合并档口。
