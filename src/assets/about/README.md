# 关于食光 · 手写信

`handwritten-letter-original.jpg` 是用户在本次会话提供的原始手写信截图，原样复制保存，尺寸 1079 × 1643。页面显示原图笔迹，不使用系统字体替代，不进行生成式改字。

`paper-fiber-original.jpg` 是用户 2026-10-28 提供并选定的真实纸纹原图，736 × 1180，原样保存。纸面以 `background-size: cover` 居中裁剪上下留白，保留纵横比例，不拉伸、不重复平铺、不重新生成纤维。桌面约 700 × 726 的纸面取原图中部约 736 × 763 区域；手机按实际纸面比例调整裁切。原始文件始终保留，原碎边蒙版、折痕、光影和墨迹独立叠加。

`AboutLetter.tsx` 通过 SVG 视窗展示正文及落款区域，排除笔记软件工具栏、页面分隔和页码控件；颜色滤镜只将墨迹从原纸底中分离，以便叠加在网页的微皱纸张上。源文件字迹、行序、标点和落款均保留。

用户第二张图片仅提供纸边形态参考，不使用其文字、绿色背景或卡通描边。原始手写图、独立纸面、折痕和纸纹分别呈现，显示视窗不变。按最新反馈恢复原笔画粗细，笔迹提取后始终沿用原始 alpha；固定 seed 噪声只在暖黑 RGB 中产生细微墨色变化，不再调整边缘透明度。不改变字体，不用侵蚀、位移或模糊滤镜，保留细弱连笔。

`paper-edge-mask.svg` 是固定的 700 × 755 透明蒙版。四边采用非周期平滑曲线，700 CSS px 宽时约 0.5–3 px 的细小起伏；不在运行时随机生成。蒙版应用于内层纸面，外层透明包裹使用两层柔和 drop-shadow。原图与文字没有位移、模糊或生成式重绘，也不会露出原截图的矩形纸底。

布局使用约 700 CSS px 宽的独立信纸，不按屏幕高度缩小。唯一的阅读滚动区为透明 dialog；高度不足时纵向滚动，按用户最新反馈隐藏滚动条外观。手机默认适宽显示，并提供“放大查看”，在同一阅读区内滚动查看原笔迹。Esc 先退出放大，再关闭信件；关闭键与放大入口位于纸张蒙版之外。引导文字已按用户后续要求删除，仅保留屏幕阅读器可读的“关于食光”标题。

日夜共用纸边、排版和折痕：白天为左上方较宽的自然窗光、象牙白纸面；夜晚为左上方局部暖台灯光、低饱和暖灰纸面，右下稍暗。按后续反馈加大受光与背光面的明暗差，光影始终位于墨迹下方。折痕亮带约为最初版本一半，移除右下角卷边与多条斜向高光。透明 `paper-wrinkles.svg` 描述展开后的短褶皱，叠加强度为 0.76；纸面已由程序噪声换成用户原图，以 multiply 叠加保留纤维层次，墨迹不做位移或模糊。交互沿用主站字体与紫色变量。无新增依赖。

`PaperUnfold.tsx` 与 `about-letter-unfold.css` 实现 1200ms 的一次性纸团展开：无字多面纸团松开，纸面轮廓舒展，原图笔迹淡入。完成后恢复原始尺寸，纸团完全隐藏，不循环、不跟随鼠标；主题切换与放大操作不会重播。系统偏好减少动态时直接显示最终信件。

背景方案为半透明网页遮罩：白天维持 0x65（约 40% 不透明度）、12px 虚化及适度降饱和。夜晚按用户明确要求恢复到“放入手写纸之前”的旧弹窗设置，与 `interface-theme.css` 中原 `.modal-backdrop` 一致：`#17131f80`（约 50% 不透明度），并沿用原 `interface.css` 的 `blur(6px)`，不另加降饱和。纸面和文字保持独立不透明。
