# 第四食堂牌匾纹理

26 张 WebP 来自用户提供的 `E:\Acntenn\第四食堂\1.jpg…7.jpg`，仅采样主牌匾及其下方灯箱区域，不包含整张就餐场景。主牌匾文字与图案使用实拍像素；源照片保留原样。

`source-manifest.json` 记录源图尺寸、以 1824×1368 审阅图为基准的四角坐标（左上、右上、右下、左下）、输出尺寸和文件大小。原图需由开发者自行提供，普通构建和部署直接使用已保存的 WebP。

重建命令：`python scripts/models/prepare-fourth-signs.py --source-dir "E:\Acntenn\第四食堂"`。离线脚本依赖 Pillow 和 NumPy，与民族食堂的处理方式一致。

`signs.ts` 通过模块 URL 引用各贴图，支持 GitHub Pages 子路径及未来域名迁移。“优品麦选”和“酱香醇厚”属于同一家转角店但使用不同招牌。

曝光修正在模型材质中完成：主牌面白色上限约为 222，下方灯箱约为 215（8 位 sRGB）；不叠加室内照明和自发光。完全过曝而丢失的照片细节不补造。照片中的价格、菜名属于现场装饰信息，不作为当前菜单、价格或营业承诺。
