# 民族食堂现场牌匾纹理

这些图片是用户提供的 `民族食堂内部/1.jpg` 至 `4.jpg` 中牌匾区域的像素提取；仅做透视校正、裁切与 WebP 压缩。保留照片里的书法字形、配色、印刷图案及反光，不把文字换成系统字体，不包含顾客或人脸。

文件用于三维模型中的实物牌匾装饰，不能当作当前菜单、价格、菜品照片或营业状态的证据。网页使用模块资源 URL，兼容 GitHub Pages 子路径；原始全景照片无需公开。

可重复生成命令：

```powershell
python scripts/models/prepare-minzu-signs.py --source-dir '<民族食堂现场照片目录>'
```

脚本需 Pillow 与 NumPy，只用于离线制作，不新增前端依赖。每张主牌匾的源文件、原始像素四角和输出尺寸均记录在脚本中。

- `bianchui-fengqing.webp`：1.jpg 的“边陲风情”。右上现场灯笼局部遮挡保留，未补画。
- `minzu-fengwei.webp`：2.jpg 的“民族风味”。
- `meishi-paidang.webp`：3.jpg 的“美食排档”。
- `lanzhou-lamian.webp`：4.jpg 的“回味无穷·兰州拉面”，包括原有“伊真味餐饮”标识。
- `student-special.webp`：4.jpg 的“学子特价套餐窗口”主体文字与鲸鱼图案，不截取其上方的小字品牌行。

- `breakfast.webp`：1.jpg 中“暖心早餐”完整主文字区域。仅截取无遮挡部分，保留原有字形及背景，可用于三维挂牌的中央文字面。

8 号“暖心早餐”整块心形标牌右下方在参考图中被顾客遮挡，未把含人物的完整矩形作为纹理，也未补造被挡区域或文字。
