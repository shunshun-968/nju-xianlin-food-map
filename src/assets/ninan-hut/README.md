价目牌压缩质量为 90，场景照片为 83。品牌标识保留照片中的真实标识；模型单独使用的南京大学校徽及南大后勤标识，须引用 `../branding/` 中已有原图。

详情面板只摘录清晰可辨的早餐套餐与饮品价格，其他商品可查看完整实拍牌。早餐牌位于独立白棚的东南侧；饮品牌位于北侧「咖啡饮品」窗口下方（用户明确指定）。晚餐使用用户补充的照片 10–13 建模，详情采用其中三张实拍，不从食材外观推断品名或价格。

方位以更新后的示意图（上西、右北）为准；east-reference.webp 保留原资源文件名以兼容既有引用。

模型的两幅装饰画使用 `east-posters.webp`，从 `east-reference.webp` 的 1600×1200 像素中裁出 `(1180,465,340,342)`，包括取景外至少 16px 安全边界，以无损 WebP 保存。体积为 122,756 字节（原参考图 307,506 字节），解码像素逐通道比对完全一致，没有重新缩放或有损压缩。两幅画原始四角坐标保持不变，在单应透视计算后统一换算裁切 UV；原参考照片继续保留。

模型中同一照片的不同取景共用 Three.js 像素源：早餐牌与烧烤牌、两幅装饰画分别复用原照片的 GPU 上传，仍保留各自 UV、纹理对象及释放生命周期，不重复上传整张照片。
